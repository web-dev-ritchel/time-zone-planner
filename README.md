# Time Zone Planner

A lightweight web tool that helps you check and compare time zones at a glance.
It starts with the Philippines (PHT) and Central European Time (CET/CEST), and you
can add any other time zone.

## Features
- Compare time zones in one table, with the same hour lined up across every row
- Switch each time zone between 12-hour (6:00 PM) and 24-hour (18:00) format
- Add, remove, and drag to reorder time zones
- Click a column to see the same moment across all zones, or jump to any date
- Handles daylight saving time automatically
- Works on desktop and mobile

## Privacy
Your time zones and format choices are saved locally in your browser only
(localStorage), so they're still there when you come back. The app has no
backend, no accounts, no tracking or analytics, and it does not collect or
send any information about you.

## Usage
Open `index.html` in any modern browser. No install or build step needed.

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – app logic
